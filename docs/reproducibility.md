# Reproducibility and portable evidence

Build a portable `Release` binary with CMake/Ninja; use GCC >=12 or Clang >=16. `cmake --preset portable-release` is available. Inputs are generated from explicit SplitMix64, a fixed generator version, typed parameters, seed and canonical little-endian encoding. Case IDs are SHA-256 over *both* canonical params and bytes. v1/v2 generator identity is immutable; v3 literal witnesses store exact original bytes and are capped at 64 KiB. `decode_case` refuses a mismatched digest, bytes, generator version, schema or shape.

`phaseshift explore --config ... --out runs/EXAMPLE` creates new SQLite evidence, not a mutable global cache. `phaseshift resume --run runs/EXAMPLE` replays an atomic scheduler transcript, verifying selected case hashes and order. `phaseshift replay --run ... --case <case-id>` rechecks stored bytes and oracle results without replacing original raw observations. For an injected wrong-answer case use `--expect wrong_answer --algorithm plugin:/absolute/path.so`.

`phaseshift export --run ... --out bundles/EXAMPLE` checkpoints the SQLite WAL, exports reports and witness files, writes `SHA256.json` over every member and independently revalidates the bundle before returning success. `phaseshift verify-bundle --bundle ...` validates file hashes, member set, SQLite config hash and canonical case regeneration. `phaseshift import --bundle ... --out runs/IMPORTED` refuses an existing target. Changes to a bundle member without an updated manifest are rejected. Even a valid manifest is **not** a cryptographic signature proving who ran the experiment; independent provenance requires external signing or cross-machine reruns.

Timing is host-dependent. The stored environment includes available CPU/kernel/compiler metadata, and samples record wall nanoseconds, available process CPU nanoseconds, Linux peak RSS, batch count, block/order seed and correctness/failure status. Missing counters are `NULL`, not zero. Independent confirmation uses disjoint seeds from discovery. Do not infer cross-hardware speedups from nominal CPU timings without a matched controlled experiment.

## Standalone source reproduction

`phaseshift reproduce --run <run> --case <ID> --algorithm <builtin> --out witness.cpp` emits a single C++20 source file with frozen literal input data, stored case/input identities, the built-in algorithm and the independent reference result. Compile with `c++ -std=c++20 -O2 witness.cpp -o witness && ./witness`. This is a correctness/replay aid; its one-shot timer is explicitly not a benchmark or independent phase-boundary confirmation. CTest compiles and executes representatives of all twelve built-in algorithm IDs, plus signed integer extreme cases and empty Top-K. For inputs larger than 2 MiB, preserve the original SQLite-backed bundle and replay via PHASESHIFT rather than generating a huge translation unit. Plugins are never exported as invented source code.
