# Reproducibility

Re-run a known case with `phaseshift replay --run runs/demo --case <case-id>`. The engine loads stored input bytes, checks SHA-256, regenerates exact bytes using generator v1 and verifies the case ID, then executes and validates the compared primary algorithm. `phaseshift export --run ... --out ...` includes SQLite, JSON, raw CSV, reports, and SHA256 manifest; check the manifest before trusting a transfer. `run.sqlite` is a schema-1 WAL database with immutable sample inserts. The operating system, compiler, CPU model, and recorded clock are provenance; absolute nanoseconds need not reproduce across machines. Timed replay does not silently replace previous measurements. For reproducible comparisons, preserve source SHA, build flags, config, kernel, and sample order. Import verification and architecture-independent replay beyond tested x86-64 remain open gates.
