# Architecture — C++20 CPU-only engine

`apps/phaseshift.cpp` dispatches the CLI; `apps/phaseshift_worker.cpp` is a dedicated process to prevent accidental test-executable recursion. `src/core.cpp` owns JSON, SplitMix64, SHA-256, generator versions and immutable little-endian case encodings. `src/algorithms.cpp` contains independent semantic oracles and reference algorithms, `src/morphology.cpp` measures observed structural features, `src/runner.cpp` owns bounded binary IPC and timing, `src/statistics.cpp` holds case-aware resampling and BH-FDR, and `src/scaling.cpp` fits empirical held-out-size growth shapes.

`src/experiment.cpp` owns validation, budgeted grid/random/stratified/adaptive selection, the SQLite-backed deterministic resume transcript, scoped adjacent-bin candidate detection, frozen independent confirmation, evidence-constrained minimization, replay and export. `src/minimize.cpp` provides parameter shrinking and literal-byte structural ddmin for arrays, Top-K, directed graph arcs and reciprocal undirected edge pairs/renumbered vertices. `src/reproducer.cpp` generates bounded standalone C++20 oracle-checked witnesses for built-in algorithms; `src/store.cpp` owns versioned SQLite migrations (current version 6), foreign-keyed observations, environment/case/algorithm identities, confirmations and evidence events.

The parent **never loads plugins**. A dedicated child loads a trusted C ABI plugin once per case and retains it across correctness calibration and paired blocks, including explicit state reset callbacks. Payloads are bounded binary frames (magic `PS01`, little-endian length) with SHA-256 case validation. One per-case worker executes a balanced series of A/B blocks; parent kill/reap, Linux resource bounds and fault-status recording prevent a faulty worker from becoming a valid timing observation. This is process fault containment, not seccomp/container isolation.

Generator v1 cases remain replayable; generator v2 provides typed morphology; generator v3 contains a deliberately capped exact byte-literal witness with the original source witness linked in SQLite. A version bump is mandatory before any future change to canonical input serialization or PRNG semantics. A case ID is SHA-256 over versioned family, canonical generator parameters, seed and complete input bytes.

The normal evidence root is `runs/<unique-name>/run.sqlite`. Human-readable reports are derived projections; replay/export/import can reject mismatched bytes/config or checksum tampering. All execution is local; no GPU, cloud or API dependency.
