## Remaining known boundary conditions

- AArch64/macOS/Windows builds, independent cross-machine performance replication, and optional hardware performance counters are **not necessary for the primary Linux x86-64 v1.0 acceptance target** and have not been tested.
- Arbitrary untrusted native code is **not securely sandboxed**; only trusted C ABI plugins are in scope. A child worker is fault containment, not complete isolation from a malicious plugin.
- The statistical validity of a selected hypothesis is not a license to run unlimited independent studies and claim global FDR. A new experiment must report its own selection/holdout family and uncertainty. The engine abstains on noisy or invalid evidence.
- Finite-size empirical scaling confirmation depends on available previously unseen sizes and independent observations; when the design or signal is insufficient it returns `NOT_CONFIRMED`, not a manufactured regime change.
- A generic repository license must be chosen by the owner if redistribution under defined permissions is desired. The specification forbids choosing it without authorization.

## Final release gate

G0–G5 require exact CTest and natural CLI acceptance evidence on the revision being proposed. G6 additionally requires passing GCC/Clang and ASan/UBSan GitHub Actions for that revision. A source file, a configured workflow, or passing results from an earlier commit alone cannot close G6.
