# Algorithm semantics

Arrays use signed `int64_t` ascending total-value ordering, with duplicates retained; no element identity or stability requirement. Top-K outputs exactly min(k,n) descending signed values, preserving duplicates. `k>n` is rejected. Graphs are directed, with 0..V-1 vertex IDs and nonnegative integral weights, no self-loops or parallel edges in generator v1. Unreachable distance is `INT64_MAX/4`, and addition saturates to that sentinel; all generated weights are <=100. 0–1 BFS rejects general-weight configurations. Comparing an algorithm with an oracle requires identical immutable canonical bytes; measured allocations performed inside the operation remain included. The first-pivot quicksort is an explicitly unsafe *performance* teaching baseline, but its returned values must still be correct. For calibration, declared `work_units` are exact arithmetic values, not elapsed time.
