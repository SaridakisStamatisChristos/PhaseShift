# Plugin ABI v1

The self-contained public C header is `include/phaseshift/plugin.h`; `plugins/examples/reverse_sort.c` builds to `reverse_sort.so`. Export `phaseshift_get_algorithm_v1()` returning a static `ps_algorithm_v1` with ABI version 1. Input bytes are borrowed and immutable; `run` may allocate output using its own allocator and MUST provide a matching `release` function. Output must be complete little-endian int64 values and must not exceed the supplied input byte count for integer-array v1. The caller always releases output through that callback. Catch all exceptions within native plugins; exceptions may not cross the C ABI. Only integer-array semantic plugins are currently supported. Worker failure does not imply sandboxing: native plugins must be trusted. Example returns reverse order on purpose, demonstrating oracle rejection.
