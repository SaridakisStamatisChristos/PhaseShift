# Inference, statistical checks, and limitations

Search records every case and keeps each secondary morphology axis at an exact frozen value when testing a numeric primary axis. The exploratory detector uses an adjacent sign reversal for `PERFORMANCE_CROSSOVER`, or a two-segment constant-mean fit versus a one-segment BIC null for `PERFORMANCE_CLIFF`. It requires a configurable practical effect plus neighborhood dominance; the candidate is an observed discrete interval, not an interpolated continuous surface. Correctness and resource failures are detected separately as transitions from repeatable `ok` to a repeatable precise `wrong_answer`, `crashed`, `signaled`, `timeout` or `out_of_memory` status, without converting censored observations to artificially large runtimes. Categorical axes are conditioned, never ordered numerically.

The selected hypothesis is frozen before new holdout cases. The default is twenty independent seed-matched *case pairs*, each containing balanced ordered per-algorithm blocks. The primary contrast is the right-minus-left log median A/B ratio (or log runtime if only one algorithm), with a case-paired percentile bootstrap (default 99% confidence), plus a Monte-Carlo paired sign-flip p-value. `detection.confirmation_confidence` and `detection.fdr_q` are configurable, with a BH-FDR step-up policy on the *one* preselected candidate within a single experiment. Both practical effect and significance must pass. Crossovers additionally require strongly supported side-specific sign changes; otherwise status is `NOT_CONFIRMED`. Frozen exact failure-status boundaries instead require every independent holdout to reproduce the expected status, not a performance p-value. Engineered operation-count calibration is deterministic and uses a separate check, not a timing CI.

**Scope**: the current procedure allows only one selected hypothesis per run. A new run or repeated exploratory reuse of a holdout creates another family of tests and invalidates claims of uncontrolled global FDR. The procedure does not prove general asymptotic complexity, a mathematical theorem, experimental causal effects, or calibrated validity for any future unmodeled input distribution. A numerical bootstrap 99% interval is not a guarantee of power or simultaneous coverage under nonstationary CPU timing. The statistical suite includes known BH reference decisions, exact nulls, known effects and a deterministic Monte Carlo null challenge.

The scaling fingerprint separately tests at least six sizes, with fresh seeds per size and held-out-size model error among constant, log, linear, n log n, quadratic and cubic curves. It must be described as empirical compatibility over the measured finite interval, never as proven Big-O. All real algorithm positive or negative findings must reference actual stored measurements and hardware provenance.

## v1.0 categorical-primary and control contract (Trillion audit closure)

An explicitly configured categorical primary axis is evaluated as an **unordered finite set**. Detection compares **distinct observed category edges within identical frozen secondary-axis scopes**, not intervals, slopes, or distances. Internal integer category references are immutable indices into the experiment's serialized `axes[primary_axis]` array; reports preserve both original string/bool labels. Both independently oracle-validated speed contrasts and exact correctness/resource-status differences can generate a candidate. Inconsistent status evidence or an invalid target observation blocks performance-based category detection; an exploratory candidate is not a confirmed discovery.

The taxonomy uses `CATEGORICAL_PERFORMANCE_CONTRAST` for a non-crossover contrast, `CATEGORICAL_PERFORMANCE_CROSSOVER` for a sign reversal of an A/B log-advantage across labels, and `CATEGORICAL_SYNTHETIC_CALIBRATION` for the deterministic work-count fixture. The existing correctness/resource categories remain unchanged. No categorical interval width, nearest-neighbor metric, continuous changepoint, or causal interpretation is claimed. Selection among category edges uses the **one-frozen-hypothesis** policy; independent 20-pair case cohorts, paired bootstrap/sign-flip tests for real performance and SQLite evidence seals are retained. If confirmation fails, a negative result and the raw observations remain in storage.

The `stratified` scheduler samples **within quantile strata for numeric axes** and **within exactly labeled category strata for categorical axes**, shuffling both strata and their members using the experiment seed. Its round-robin allocation covers categories before repeated sampling when the design/budget permits. `adaptive_partition` on categorical axes prioritizes unseen category contrasts within a previously measured conditioned scope; its configured deterministic random-exploration quota still applies. Restart and resume use persisted scheduler transcripts and RNG states, never a fresh implicit random seed.

**Negative-control acceptance rule (predeclared before any new holdout measurements):** one additional fresh-seed control case is collected after paired confirmation. Its primary and secondary algorithm results must pass independent output-oracle and worker-status validation; invalid or censored results veto a positive verdict. Where a third axis value exists, use a separately observed design point; where it does not, collect a fresh-seed repeat of the baseline category/value and say so explicitly in the report. A distant point can legitimately have another performance regime; without a predeclared null effect, the engine **does not** require its timing ratio to match either side. Thus this is an *execution-validity negative-control gate*, not a universal absence-of-effect test. The same baseline validity recheck is applied to exact correctness/resource-status confirmations. The control case is outside the 20 paired seeds and is not counted toward the sealed effect estimate.

Every in-flight worker in `confirm`, `intervene`, and witness minimization is passed the owning operation's remaining **monotonic absolute deadline**. An exhausted confirmation is rejected as `NOT_CONFIRMED` with partial samples preserved and a nonzero CLI result; an exhausted intervention produces a partial `interventions.json` and an explicit nonzero result. Performance minimization fails closed rather than promoting an incompletely tested witness. No absolute hard deadline is inferred for unrelated unbounded interactive/replay commands. Numerical scalar shrinking is intentionally **not applicable to unordered categorical contrasts**; the engine refuses that minimizer instead of inventing a categorical distance. The saved frozen pair can be replayed/exported.
