# Inference, statistical checks, and limitations

Search records every case and keeps each secondary morphology axis at an exact frozen value when testing a numeric primary axis. The exploratory detector uses an adjacent sign reversal for `PERFORMANCE_CROSSOVER`, or a two-segment constant-mean fit versus a one-segment BIC null for `PERFORMANCE_CLIFF`. It requires a configurable practical effect plus neighborhood dominance; the candidate is an observed discrete interval, not an interpolated continuous surface. Correctness and resource failures are detected separately as transitions from repeatable `ok` to a repeatable precise `wrong_answer`, `crashed`, `signaled`, `timeout` or `out_of_memory` status, without converting censored observations to artificially large runtimes. Categorical axes are conditioned, never ordered numerically.

The selected hypothesis is frozen before new holdout cases. The default is twenty independent seed-matched *case pairs*, each containing balanced ordered per-algorithm blocks. The primary contrast is the right-minus-left log median A/B ratio (or log runtime if only one algorithm), with a case-paired percentile bootstrap (default 99% confidence), plus a Monte-Carlo paired sign-flip p-value. `detection.confirmation_confidence` and `detection.fdr_q` are configurable, with a BH-FDR step-up policy on the *one* preselected candidate within a single experiment. Both practical effect and significance must pass. Crossovers additionally require strongly supported side-specific sign changes; otherwise status is `NOT_CONFIRMED`. Frozen exact failure-status boundaries instead require every independent holdout to reproduce the expected status, not a performance p-value. Engineered operation-count calibration is deterministic and uses a separate check, not a timing CI.

**Scope**: the current procedure allows only one selected hypothesis per run. A new run or repeated exploratory reuse of a holdout creates another family of tests and invalidates claims of uncontrolled global FDR. The procedure does not prove general asymptotic complexity, a mathematical theorem, experimental causal effects, or calibrated validity for any future unmodeled input distribution. A numerical bootstrap 99% interval is not a guarantee of power or simultaneous coverage under nonstationary CPU timing. The statistical suite includes known BH reference decisions, exact nulls, known effects and a deterministic Monte Carlo null challenge.

The scaling fingerprint separately tests at least six sizes, with fresh seeds per size and held-out-size model error among constant, log, linear, n log n, quadratic and cubic curves. It must be described as empirical compatibility over the measured finite interval, never as proven Big-O. All real algorithm positive or negative findings must reference actual stored measurements and hardware provenance.
