# Inference and exclusions

Exploratory 1D scans reduce repeated measurements by the median and fit a two-segment constant-mean model. Model selection uses `BIC_null - BIC_two_segment > 6`, a practical effect threshold and a local contrast dominance rule. A discrete boundary is located between evaluated bins; no interpolation is claimed. Confounded multi-axis sweeps abstain rather than assert causality. This detector is a minimal functional baseline and not yet a calibrated generalized changepoint method. Synthetic confirmation uses 20 independent-seed case-level holdouts on each side and checks exact work-count difference; it is deterministic, so a timing CI is inapplicable. A single frozen candidate per experiment can be confirmed on independent cases (20 per neighborhood side by default). A deterministic-seed, 20,000-resample percentile bootstrap over **case-level medians** forms a two-sided 99% interval for right-minus-left log performance; the interval must lie wholly beyond the predeclared log practical-effect bound. Case-level resampling preserves paired A/B execution within a case, and batches are not independent cases. The one-candidate isolated holdout has no internal multiplicity adjustment; multiple repeated experiments or many candidate hypotheses require an additional prespecified family-wise or FDR policy. Evidence is empirical, host-specific and not causal.
