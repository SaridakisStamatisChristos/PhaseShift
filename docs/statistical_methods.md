# Inference and exclusions

Exploratory 1D scans reduce repeated measurements by the median and fit a two-segment constant-mean model. Model selection uses `BIC_null - BIC_two_segment > 6`, a practical effect threshold and a local contrast dominance rule. A discrete boundary is located between evaluated bins; no interpolation is claimed. Confounded multi-axis sweeps abstain rather than assert causality. This detector is a minimal functional baseline and not yet a calibrated generalized changepoint method. Synthetic confirmation uses 20 independent-seed case-level holdouts on each side and checks exact work-count difference; it is deterministic, so a timing CI is inapplicable. No real timing result is labeled confirmed without a statistically valid 99% paired-case confidence interval and multiple-hypothesis policy (not yet implemented). Batch invocations are not counted as independent cases.
