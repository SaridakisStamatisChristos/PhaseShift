# Executed synthetic search ablation

`synthetic_ablation_2026-11-20.csv` was produced by `phaseshift ablate --config configs/adaptive_sparse.json --out <unique-directory>` on Linux 6.18.57, GCC 14.2.0 Release, AMD EPYC 9V74 virtualized CPU. Each strategy receives **24 discovery-case evaluations** on the same seeded deterministic operation-count fixture (`x=0..63`, known threshold=24). After a candidate is discovered, 40 additional independent holdout cases (20 each side) are used before recording `CONFIRMED`; thus total case counts are not equal across methods, while discovery-case budgets are equal. Wall times include confirmation overhead and must not be represented as pure search-overhead comparisons. The synthetic fixture is not a real algorithmic speedup. See ignored run directories for full raw observations. Repeating may change elapsed seconds without changing work-count truth.
